- The keyboard-screen protocol was **reverse-engineered** for interoperability. It is **not** provided, approved or supported by the keyboard manufacturer.
- Uploading **writes to the keyboard screen's flash memory** and replaces its custom image. Back up anything you want to keep, and keep the manufacturer's official software handy to restore the factory image.
- Only the RK N99 has been tested. Using it with any other model, firmware version or modified code is especially risky.
